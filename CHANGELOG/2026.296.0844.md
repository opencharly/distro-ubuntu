# 2026.296.0844 — chore(clawsweeper): pin the review candy to the scanner-baked commit

## Summary

Moves the review image's candy pin to `layer-clawsweeper#6` (`1680a5e`), which pre-installs the engine's
TruffleHog input scanner into the image user's private cache.

Without it the engine refuses every review:

```

sensitive input before retrying.
```

its own input — because the scanner is bootstrapped by download and this image never installed it.
