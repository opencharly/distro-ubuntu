# 2026.296.0754 — feat(clawsweeper): the review image box and its disposable bed

## Summary

The consumer half of the ClawSweeper advisory lane: a box that builds the review image and a
disposable bed that proves it live.

- **`box/clawsweeper-review`** composes the pinned review candy (`layer-clawsweeper@2524e36`) on
  `ubuntu:24.04`. The engine, its Node/pnpm/Codex pins, the Ollama Cloud `responses` configuration and
  the `opencharly` target-profile overlay all come from the candy; the box adds the base, the platform
  and the distro chain.
- **`distro:` carries BOTH tags** (`ubuntu:24.04` and `ubuntu`). With the versioned tag alone the
  bootstrap ran but the candy's `distro: ubuntu: package:` list was never installed — the Node step
  died on `tar (child): xz: Cannot exec`, because `xz-utils` was never there. Measured: `xz-utils` in
  the generated Containerfile goes 0 → 1 with the second tag.
- **`check-clawsweeper-review-pod`** is the R10 proof: a disposable pod builds a two-commit fixture
  whose second commit turns `add()` into a subtraction, then runs the real `clawsweeper-review`
  entrypoint over it, and asserts a report came out and nothing died on the image's own permissions.

**What a check bed can and cannot prove.** A check bed exports NO secret, so `OLLAMA_API_KEY` can never
resolve in an assert-only step — the original key guard was a DEAD assertion (`an assert-only step
resolves only the runner's auto-exported variables`). There is no key-shaped condition here now, and no
faked verdict either (R8): the bed proves the image converges, the entrypoint is invocable, the fixture
works, and the engine reaches the model boundary. The live model round-trip is the advisory workflow's
job, where the org key exists.

## The validator's BLOCK — how it was closed

The block was right: the keyless path `exit 0`ed before `clawsweeper-review` was ever called, so the
bed proved less than its description said. The check now exercises the entrypoint unconditionally and
asserts the engine's report and the absence of the permission failure that killed every review before
`layer-clawsweeper#5`. The body no longer claims a verdict it did not obtain.
