## Why — measured on a real review

decision and a report, then failed on the one thing whose contract is a strict JSON object:

```console
[review] 13:24:33Z shard=0/1 start-comment=skipped #0
[review] 13:30:55Z decision-repair-turn #0 failed
[review] 13:30:55Z shard=0/1 done #0 decision=keep_open confidence=low action=kept_open
codex-failure classification=content_or_output
##[error]clawsweeper-review exited 1; the redacted output is posted as the comment.
```

`confidence=low` is the model saying the same thing the repair turn did. The engine-side
semantics are deliberately unchanged — an engine failure still exits 1 and still reddens the
advisory check.
