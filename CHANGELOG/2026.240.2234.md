# 2026.240.2234 — feat: advance candy refs to their latest tags (Phase-4 distro sweep)

## Summary

The candy de-submodule cutover (charly #409) moved all candies to standalone repos. This PR advances every `@github` candy pin in distro-ubuntu to the owning repo's latest tag, so the boxes resolve the post-cutover standalone candy repos at current versions. 34 repos bumped across 3 charly.yml files (68 pin lines, 34+/34-).

## RCA — why the pins were stale

The Phase-4 cutover (charly #409) deleted the in-repo candy dirs and moved each candy to a standalone repo. The box repos' `@github` pins were NOT swept in that cutover — the #409 CHANGELOG documents this as the "separate Phase-4 box-repo track" (the distro sweep). The pins therefore lagged the standalone repos' latest tags by up to 2 days (e.g. layer-pixi v2026.237.457 → v2026.239.1634). This PR is that sweep for distro-ubuntu.
